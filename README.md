# TagTeam---SeniorDesign1
Browser based video game with in game payments.

Echo is Christopher Stone
AmberStars is Tyler Ambrose


Tag Team is a 2 player web based strategy game with in game purchases.
The two players will work together to complete the given objective, and once the goal is reached the player will earn gold.
This gold can be used for power ups.
Stripe will be implemented for the ability to purchase premium currency.
Premium currency will not give the player any advantages, it will only allow them to purchase cosmetic items.
